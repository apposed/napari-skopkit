# napari-skopkit

Run [scikit-ops](https://github.com/apposed/scikit-ops) ops from napari: pick
an op, fill in its form, and the result comes back as a layer. Each op runs in
its own environment, built the first time you use it.

This is an early development release, for early adopters. Things will change.

```sh
pip install --pre napari-skopkit
```

Then open **Plugins ▸ scikit-ops ▸ Ops** in napari.

- Source: https://github.com/apposed/napari-skopkit
- Docs: https://scikit-ops.readthedocs.io
